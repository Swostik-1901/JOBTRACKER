Is my data private?

Each account only ever sees its own applications. Nothing is shared or public.

Can I upload different resume versions?

Yes — attach the exact file you sent to each application, so you can always match what a recruiter received.

Does it work on mobile?

Yes, the board and forms are fully responsive.
